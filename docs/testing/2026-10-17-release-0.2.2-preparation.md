## Actual signed-app installation

Clean baseline clones were preserved separately from working guests. Tests used macOS 27.0.1 (26A434) and macOS 26.6 (25G72), dedicated local accounts and user-owned Applications folders. Production signing keys stayed on the host.

Both clean guests downloaded the signed candidate in Safari with quarantine retained. Normal first-launch dialogs reported that Apple checked the app and detected no malicious software; Open launched successfully without an Open Anyway override. Finder moved the downloaded app; on 26 the last move from the test home into its Applications folder used ordinary file management. Both ran the exact signed candidate executable from the permanent Applications path. Strict signatures, stapled tickets and Gatekeeper acceptance passed in each guest. The clean app showed version 0.2.2, two-second refresh and unavailable VM sensors as dashes; automatic update checks were off by default. The fresh VMs had no developer SDK, so the unmodified Apple stapler utility from host Xcode was used for ticket verification.

On both OS versions, a distinct ad-hoc test harness drove real Sparkle installation of the production-signed candidate over a verified public 0.2.1 copy while the old app was closed. Installed executable hashes, signature/ticket/Gatekeeper, five-second sampling preference, automatic checks off and existing launch-at-login registration all passed. The installed app was manually reopened; a full guest restart then verified one permanent-path 0.2.2 process, five-second interval, automatic checks off and enabled launch at login.

The separate running-app harness encountered macOS App Management authorization for the VM account; that attempt was cancelled. No security settings were disabled, and no administrator password or privileged helper was used to make the successful cold-install tests pass. Cold installation plus manual reopen is not claimed as proof of production automatic self-update/relaunch. The live HTTPS feed and normal app-owned upgrade/relaunch must be checked after publication.
