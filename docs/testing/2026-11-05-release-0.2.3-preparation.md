## Open before signing

Synthetic clicks were refused in the guests because the helper has no Accessibility permission, and that was not granted. System appearance could not be switched either: the `--snapshot` result above is offscreen and does not replace a live check. These need a person, on both OS versions:

- Live dark appearance of the menu bar and panel.
- Opening the panel by clicking the meter; close button and outside-click dismissal.
- Gear and right-click menus, pause/resume, refresh interval selection, scrolling to the last section.
- Manual update check against the production feed, including Sparkle's own update UI, which ships in the changed framework.
- Launch at login after guest logout/login.
- Physical host: the candidate runs here and shows live readings, but no comparison with trusted readings was made. VM results say nothing about sensor compatibility.
