# Hardware checks — 2026-10-12

MyStat 0.1.3 passed a hardware smoke check on an M5 Pro MacBook Pro after its upgrade to macOS 27.0.1. The maintainer also reported a successful test on an M5 MacBook Air running macOS 26 on the previous evening. These results expand the recorded hardware coverage without changing the app or making a general macOS 27 sensor-support claim. No new release is needed for this documentation update.

## M5 Pro MacBook Pro: observed check

- Host: Apple M5 Pro, 18 CPU cores, 20 GPU cores, 48 GB RAM; macOS 27.0.1, build 26A434.
- App: MyStat 0.1.3. Diagnostics and workload checks used the existing local build; source checkout `00fe53a` includes the 0.1.3 application sources from release commit `ba0c170` plus documentation changes. This session did not independently establish the local executable's build provenance.
- The live dropdown rendered correctly and continued updating CPU, per-core, memory, GPU, temperature, fan, and power readings.
- Memory pressure was 7%, matching 100 minus the 93% availability reported by macOS `memory_pressure -Q`. Physical memory and CPU count matched system queries.
- A ten-second workload used six CPU workers. MyStat diagnostics sampled before, during, and after it, with macOS `top` sampled concurrently. The workload ended automatically.

| Reading | Before workload | During workload | After workload |
| --- | ---: | ---: | ---: |
| MyStat CPU usage | 14.1% | 44.8% | 25.1% |
| macOS `top` CPU busy, final two interval samples | 13.5–14.2% | 43.7–46.4% | 23.4–24.7% |
| MyStat CPU power estimate | 3.3 W | 48.7 W | 7.4 W |
| MyStat CPU temperature | 32.7°C | 91.0°C | 47.9°C |
| MyStat whole-Mac power estimate | 7.7 W | 72.5 W | 20.7 W |

The CPU samples cover similar, not identical, intervals. Other desktop activity continued throughout; the final sample is recovery from the test workload, not a controlled idle measurement. Power and temperature responded to load, but were not compared with an independent reference. Both fan counters returned 0 rpm during these short samples; fan spin-up was not tested. GPU activity varied during normal desktop use, without a controlled GPU workload. Neural Engine activity was not deliberately exercised.

Additional checks:

- `./scripts/test.sh` passed hardware mapping/conversion assertions, updater policy tests, and all four appcast tests.
- A separate compile of the C and Swift application sources succeeded using Apple Swift 6.3.3 and the macOS 27.0 SDK. It did not replace the running app.
- Deep strict code-signature verification passed for the local app and the installed 0.1.3 copy.
- No macOS 27 MyStat crash report was found in the inspected user/system diagnostic-report folders. The existing report predated the OS upgrade; this was not a long-duration stability test.
- After the checks, the local build was quit and the installed copy was launched. Process inspection confirmed exactly one MyStat process at the installed Applications location; its UI showed 0.1.3 with live readings.

## M5 MacBook Air: maintainer-reported check

The maintainer reported successfully testing MyStat on an M5 MacBook Air running macOS 26 on the evening of 2026-10-11. The app version, exact OS point release/build, memory configuration, individual features exercised, and sensor comparisons were not recorded in the report. This is a reported successful use result, not an independently observed sensor-validation pass.

## Remaining limits

macOS 26 remains the release qualification target. The M5 Pro check provides physical-hardware evidence of basic operation on macOS 27.0.1, while the CLPC mappings remain experimental. Independent power/temperature accuracy checks, controlled GPU/Neural Engine workloads, fan behavior, sleep/wake, and longer stability testing remain outside this pass. These results do not establish compatibility for other chip/OS combinations.

Update validation is recorded separately in the [0.1.3 VM test report](2026-10-11-release-0.1.3.md). Preserve the macOS 26 and 27 VM baselines for future installation and update regression testing; virtual machines do not replace physical sensor checks.

Only this reviewed summary is published. Raw diagnostics and temporary test artifacts remain excluded from Git. Documentation and the M5 Pro checks used substantial assistance from OpenAI Codex; the MacBook Air result was supplied by the maintainer.
