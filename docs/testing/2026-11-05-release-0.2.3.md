## Signed upgrade before publication

Fresh clones of the clean baselines: macOS 26.6 (25G72) and macOS 27.0.1 (26A434), Parallels 27.0.3. Each guest started from the exact public 0.2.2 archive, checked by hash. A test harness carrying Sparkle 2.10.0, the version inside 0.2.2, drove a real Sparkle installation of the signed candidate from a localhost feed signed with the production key, which stayed on the host.

On both guests the installed executable matched the hash above, and strict signature, stapled ticket and Gatekeeper checks passed at the permanent app path. The five-second interval and automatic checks off were preserved. The reopened app ran one permanent-path process with Sparkle 2.10.1 and showed its panel.

## Production updater verification

Signed feed PR #31 merged after required CI passed, at `6aef2fe168375f99867311280526beba1bca421b`. The live HTTPS feed matched the reviewed signed file byte for byte and passed signature verification.

On macOS 26.6 and 27.0.1 each guest was reset to the exact public 0.2.2 executable (`eead82e405a0b516ed26055a0a4c8872e00e46f12aecbe4485dfa06497a6fbb7`) with the app closed. The same harness then used the production feed URL, so Sparkle 2.10.0 read the live feed and downloaded the public release. Each guest installed the exact release executable above. Strict signature, stapled ticket and Gatekeeper checks passed, and the five-second interval and automatic checks off were preserved. A further check from the installed 0.2.3 reported no update. The reopened app ran one permanent-path process.

## Not tested for this release

- Quarantined browser download and first-launch dialog with the signed build.
- Launch at login and its continuity across restart. No login item was registered in these guests.
- Update installation while the app is running, and relaunch through the app's own UI.
- Clicking through Check for Updates in the app's UI, and Sparkle's update screens. The harness drove Sparkle without them.
- The unwritable-install, interrupted-download and cancel cases in the guests. The host integration suite covers download failures and cancel with disposable fixtures.
- Independent sensor accuracy and sleep/wake. macOS 27 power-sensor mappings remain experimental.
