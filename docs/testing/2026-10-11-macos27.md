## Unattended operation

The dedicated local account is `amystat-test` (UID 501), as created during interactive setup. No password is stored in the repository or test scripts. Apple Account sign-in was not configured.

Automatic login and no screen-lock password were enabled with the owner's confirmation. A full guest restart reached the account's desktop without user intervention. After restart, `sysadminctl -autologin status` identified the test account and `sysadminctl -screenLock status`, run in its GUI login session, reported screen locking off. The clone retained both settings and logged in automatically. Parallels guest commands run without interactive authentication. FileVault is off, and system/display sleep are disabled in this disposable guest.

Host-home sharing, cloud folders, shared clipboard, automatic volume sharing, and host/guest application sharing are disabled. The preserved baseline contains no MyStat installation.
