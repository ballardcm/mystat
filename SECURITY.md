# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through GitHub's
[Report a vulnerability form](https://github.com/ballardcm/mystat/security/advisories/new).
Do not include vulnerability details in public issues or pull requests.

Include the affected MyStat version, macOS version, steps to reproduce, and the
potential impact. Remove credentials, personal information, and unrelated
diagnostics from any examples or attachments.

Security fixes are provided in the latest stable release. If you can safely do so,
check whether the issue also affects that release; reports about older versions
are still welcome.

For ordinary bugs and feature requests, use
[GitHub Issues](https://github.com/ballardcm/mystat/issues).
